# Active Task Packets

Create one `issue-<number>-<slug>.md` file from the [task packet template](../../templates/task-packet.md) when an issue moves to `status:in-progress`.

A packet is a handoff cache, not a second specification. It links to the issue and canonical contracts instead of copying them. Remove it after completion once durable decisions have moved to specifications/ADRs and GitHub reflects final status.
